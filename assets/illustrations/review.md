# 삽화 검수 기록

2026-09-13. 표지, 1~16화, 공유 이미지까지 18개 파일을 직접 보고 본문의 등장인물과 대조했다. 내장 `image_gen`으로 16개 파일을 수정했다. 기존 파일명과 표시 크기를 유지했다.

공통 기준은 굵은 검은 먹선, 평면 채색, 옅은 살색 피부, 검은 머리의 선명한 하이라이트다. 낮 사무실의 흰색·회색과 밤 장면의 청회색·작은 따뜻한 조명은 각 장면의 시간대에 맞게 유지한다. 나무·옷감의 미세 질감과 부드러운 피부 명암이 두드러진 후반 장면을 초반 그림체에 가깝게 정리했다.

유현은 사용자 지정 신민아 사진의 얼굴 인상을 참고했다. 검은 단발을 유지하고 볼의 볼륨, 눈·코·입매, 둥근 턱끝을 반영했다. 추가 피드백에 따라 14화는 얼굴을 확대해 광대 아래부터 턱까지의 윤곽을 완만한 곡선으로 다시 그린 뒤 전체 장면에 반영했다. 진지한 표정과 미소, 고개 각도는 각 장면을 따른다.

| 파일 | 검수 및 반영 내용 |
|---|---|
| `cover.webp` | 유현의 새 얼굴과 둥근 턱선 적용. 뒤편 영선의 나이 인상과 짧은 파마를 5화에 맞춤. |
| `ep1.webp` | 유현의 새 얼굴 기준. 볼과 턱끝을 부드럽게 보정. |
| `ep2.webp` | 서 있는 유현의 얼굴을 1화 기준에 맞춤. |
| `ep3.webp` | 중앙 유현의 얼굴 보정. 민석·도경과 모니터 뒷면 유지. |
| `ep4.webp` | 유리의 묶은 머리와 얼굴, 사무실 팔레트가 기준에 부합하여 유지. |
| `ep5.webp` | 뒤쪽 테이블의 유현 얼굴 보정. 유리·영선·민석·도경 유지. |
| `ep6.webp` | 유현의 미소와 둥근 얼굴 반영. 얼굴 명암을 먹선·평면 채색으로 추가 정리. 하늘의 짧은 머리와 둥근 안경을 이후 회차 기준으로 유지. |
| `ep7.webp` | 은서와 임재헌의 독립적인 외모, 사무실 팔레트가 적절하여 유지. |
| `ep8.webp` | 술집 안 네 사람을 하늘·민석·도경·유현으로 바로잡음. 빈 의자와 밖의 윤태섭 유지. |
| `ep9.webp` | 도경의 성인 얼굴과 헝클어진 머리, 먹선·하이라이트를 초반 기준에 맞춤. |
| `ep10.webp` | 유현의 새 얼굴과 피부 명암, 머리 하이라이트 보정. 버스 안 통화와 겨울 해질녘 유지. |
| `ep11.webp` | 문가 하늘의 짧은 머리·둥근 안경을 6화에 맞춤. 민서의 외모는 유지. |
| `ep12.webp` | 도경의 얼굴·머리와 질감 보정. 부상한 발, 붕대, 목발과 집 안 대응 장면 유지. |
| `ep13.webp` | 유현의 얼굴·머리·먹선 보정. 꺼진 모니터와 국소 조명 유지. |
| `ep14.webp` | 형광 초록을 차분한 초록으로 낮춤. 유현의 광대 아래 볼선과 턱 윤곽을 확대 보정. |
| `ep15.webp` | 앞의 하늘을 6화의 짧은 머리·둥근 안경으로 통일. 뒤의 유현 얼굴 보정. |
| `ep16.webp` | 유현의 옆얼굴과 둥근 턱선, 질감 보정. 닫힌 가방과 밖에서 통화하는 두 사람 유지. |
| `share.jpg` | 유현과 영선 얼굴 보정. 제목과 두 줄 소개 문구 유지. |

회차와 표지는 1672×941 WebP, 공유 이미지는 1200×630 JPEG다. 원본 생성 결과를 확인한 뒤 크기를 맞추고 해당 형식으로 저장했다. 실제 전송한 수정 프롬프트와 선택한 생성 원본은 `prompts.json`에 기록했다.
